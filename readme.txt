Herizon Cars 1.2.0
Requires Hello Elementor, WordPress 6.5+, PHP 8.2+.
Elementor / Pro remain the content editor. Optional custom widgets register when Elementor is active.
Configure Appearance > Herizon Cars. Contact channels start empty; the floating CTA stays hidden until configured.
Background fallback #101010. Colors and fonts follow the active Elementor kit.
Development: pnpm install --frozen-lockfile; pnpm lint; pnpm test; pnpm build.
Runtime dependencies GSAP 3.13.0 (GSAP standard license) and Lenis 1.3.23 (MIT) are bundled locally.
Theme PHP/CSS/JS adaptation by Abel Hechavarria; GPL-2.0-or-later, except third-party dependencies under their licenses.
Source and handoff documentation remain in the project docs/ and specs/ directories.
HCars Button is available in Elementor and as the independent Gutenberg block herizon-cars/button.
Local Font Awesome Free 6.7.2 SVG icons; license preserved in assets/licenses/fontawesome-free-LICENSE.txt.
